# Checklist para la exposición

## Una semana antes

- [ ] `npm install` funciona en la laptop que se llevará a clase.
- [ ] `npm run build` termina sin errores.
- [ ] `npm test` pasa las 16 pruebas.
- [ ] Probar la demo completa con la **Guía** de principio a fin.
- [ ] Guardar una copia del repositorio (USB o carpeta comprimida) y las capturas de `docs/img/`.

## Una hora antes

- [ ] Cargar la laptop y llevar cargador.
- [ ] Probar el proyector y la resolución (ideal 1600×900 o 1920×1080).
- [ ] Abrir la app en Edge/Chrome a pantalla completa, zoom 100 %.
- [ ] Cerrar pestañas y aplicaciones que consuman GPU.
- [ ] Verificar que el audio no sea necesario (la demo es visual).

## Cinco minutos antes

- [ ] `npm run dev` (o `npm run preview` con la versión de producción).
- [ ] Confirmar que el globo, el satélite y los paneles cargan.
- [ ] Pulsar **Guía**, avanzar un paso y cerrar; así se comprueba que la tarjeta funciona.
- [ ] Dejar la app en el modo **Puntual** y en **10×**.
- [ ] Tener abierto `docs/GUION_EXPOSICION.md` en otra ventana o en el móvil.

## Durante la demo

- [ ] Empezar con el gancho de 40 s, no con la lista de tecnologías.
- [ ] Usar la **Guía** para no perderse; cada paso configura la app.
- [ ] Al entrar a **Celular** o **Conformada**, la simulación se pausa y reposiciona: decirlo, no parece un error.
- [ ] Si el satélite se alejó de Lima, pulsar **Ahora** o cambiar de modo.
- [ ] En la síntesis, esperar el toast de cobertura antes de hablar de los números.
- [ ] Cerrar con el triángulo ganancia–cobertura–capacidad.

## Plan B

- [ ] Si falla la laptop: usar las capturas `docs/img/01-general.jpg` … `07-teoria.jpg`.
- [ ] Si falla el proyector: explicar con la captura de `05-conformado.jpg` y el diagrama del patrón.
- [ ] Si la app va lenta: 4×4 u 8×8, desactivar **Ganancia**, cerrar el navegador y reabrir.

## Después

- [ ] Anotar las preguntas que no se supieron responder.
- [ ] Subir el repositorio a GitHub y compartir el enlace.
- [ ] Guardar una captura de la demo para el informe.
