BeamLab LEO

Versiones portables · sin instalación · Windows, macOS y Linux con navegador

Cada versión es un archivo HTML independiente. Descárgala y ábrela con doble clic. Actualizar no borra las versiones anteriores: tú eliges cuál usar.
Windows: el instalador se desinstala desde Configuración → Aplicaciones (o su uninstall.exe); el portable se borra como cualquier archivo. Ubuntu: sudo apt remove beamlab-leo para el .deb; el AppImage se borra. macOS: arrastra la app a la Papelera.
